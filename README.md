# hh-skills-parser

Python-скрипт для парсинга вакансий hh.ru, сбор ключевых навыков и построения статистики.

## Что делает

1. **Сбор вакансий** — обходит до 20 страниц поиска hh.ru (параметры URL как в ТЗ: `search_field=name/company_name/description`) и собирает вакансии в формате `{id, name, url, employer, area, salary}`.
2. **Фильтр релевантности** — вакансия попадает только если все слова запроса есть в названии (с учетом основы слова и синонимов). Лишние вакансии (например, «Сотрудник склада» на запрос «база данных») отбрасываются и пишутся в `skipped.json`.
3. **Сбор навыков** — заходит до 200 вакансий и собирает список «Ключевых навыков» со страницы.
4. **Статистика** — считает уникальные навыки, нормализуя написания (`C#`+`С#`, `.NET`+`.Net`+`.net`, `C++`+`С++`). Подсчитывает количество и долю (share) вакансий с каждым навыком.

## Запуск

```bash
# Поставить звезду
# Скачать репозиторий
git clone https://github.com/gKonstantin17/hh-skills-parser

cd hh-skills-parser

# Установить зависимость (только requests, остальной stdlib)
python -m pip install requests

# Основной запуск
python hh_parser.py "C#" "база данных" "Frontend"
```

### Доступные флаги

| Флаг | Значение | По умолчанию |
|------|----------|--------------|
| `--pages N` | Сколько страниц выдачи просканировать | `20` |
| `--limit N` | Сколько вакансий открыть для сбора навыков | `200` |
| `--delay N` | Пауза между запросами (секунды) | `0.8` |
| `--captcha-wait N` | Сколько ждать при капче (секунды) | `45` |
| `--out P` | Папка для результатов | `results` |

## Результаты (по запросу)

Запрос создаёт папку внутри `results/`:

- `results/c_sharp/` — запрос **C#**
- `results/база_данных/` — запрос **база данных**
- `results/frontend/` — запрос **Frontend**

Внутри каждой папки 4 файла (JSON, UTF‑8):

| Файл | Содержимое |
|------|------------|
| `vacancies.json` | Отобранные вакансии, формат: `{id, name, url, employer, area, salary}` |
| `skipped.json` | Вакансии, отброшенные как нерелевантные, с причиной |
| `vacancies_skills.json` | Тот же набор вакансий + `{skills: [string, ...]}` |
| `stats.json` | Статистика: `vacancies_total, vacancies_parsed, vacancies_with_skills, distinct_skills, skills: [{skill, count, share}, ...]` |

Также сохраняется `results/run.log` — сводка всего прогона.

## Проверка

Странным лишним вакансиям проверяется (скрипт из `run.log`:

- 0 нарушений: каждая вакансия в выборке содержит слова запроса;
- «Сотрудник склада», «Грузчик», «Кладовщик» и т. п. — **только** в `skipped.json` (при запросе «база данных»: отсеяно 285 из 311, из них 65 складских/логистических);
- Формат JSON и счётчики `skills` сверены с ТЗ — данные согласованы.

## Настройки защиты от блокировки

- Используются браузерные заголовки (`User-Agent`, `Accept-Language`, `Sec-Fetch-*`);
- Пауза 0.8 с между запросами, плюс случайная пауза до 0.35 с;
- При получении капчи (hh.ru возвращает страницу с `hcaptcha`/«Подтвердите, что вы не робот») скрипт ждет `--captcha-wait` секунд (по умолчанию 45), затем делает новую сессию и повторяет запрос;
- Максимум 4 попыток подряд; если капча ловится постоянно — нужно сделать паузу вручную и перезапустить с большим `--delay`.

## Требования

- Python 3.9+;
- Доступ к интернету к `hh.ru`;
- Команда `pip install requests`;
- ОС: Windows, Linux или macOS.

## Лицензия

Свободный проект. Данные с hh.ru используются в соответствии с их правилами.
